# Instituto Nova Horizonte

Site institucional estático em português, com HTML, CSS e JavaScript.

Site: https://ram-ismael.github.io/Instituto-Nova-Horizonte/

## Desenvolvimento local

Execute `python3 -m http.server 8000 --directory dist` e abra http://localhost:8000.

Os ficheiros do site estão em `dist/`. Não é necessário instalar dependências ou compilar.

## Publicação

O GitHub Actions publica a pasta `dist/` no GitHub Pages a cada envio para `main`.
O workflow também pode ser executado manualmente na secção Actions do repositório.

## Conteúdo demonstrativo

O site inclui dados institucionais fictícios. Os links para o portal e candidaturas
são elementos de apresentação; não existe backend académico neste projecto.
