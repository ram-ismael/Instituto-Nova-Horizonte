# Instituto Nova — Design system

## Identidade

O símbolo une um **N ascendente**, uma estrutura aberta e um percurso: conhecimento, crescimento e ligação ao futuro sem recorrer aos clichés do livro ou do chapéu de graduação. O contentor arredondado transmite segurança institucional; a linha ascendente comunica evolução.

| Primary / Navy 950 | `#071B3A` | marca, fundos institucionais, texto forte |
| Primary / Blue 600 | `#2F6BFF` | CTA, links, estados activos |
| Secondary / Blue 100 | `#E7EFFF` | superfícies informativas |
| Accent / Teal 500 | `#11B7A3` | progresso, destaques, sucesso |
| Background | `#F7F9FC` | fundo geral |

## Tipografia

- Títulos: **Manrope**, 700–800, tracking negativo.
- Interface e texto: **Inter**, 400–700.
- Escala: Display 72/76, H1 56/60, H2 44/50, H3 24/30, Body 17/28, Label 14/20.

## Componentes

- Botões: altura 48–54 px; raio 14 px; foco visível de 3 px; primário azul e secundário branco/contorno.
- Cards: raio 20–28 px; borda `#DDE5F0`; sombra `0 18px 60px rgba(7,27,58,.08)`.
- Inputs: altura mínima 52 px; label persistente; erro abaixo do campo.
- Ícones: traço 1.8–2 px, cantos redondos, grelha 24 px.
- Espaçamento: base 4 px; escala 8, 12, 16, 24, 32, 48, 72, 96.

## Ficheiros de marca

- `dist/assets/logo-mark.svg`: símbolo independente e ícone de aplicação.
- `dist/assets/logo-horizontal-dark.svg`: versão principal para fundos claros.
- `dist/assets/logo-horizontal-light.svg`: versão invertida para fundos escuros.
- `dist/assets/favicon.svg`: versão simplificada para 16–32 px.

Todos os SVG são editáveis e podem ser importados directamente no Figma.

O ficheiro `dist/assets/figma-ui-kit.svg` reúne num único quadro a marca, paleta, tipografia, botões, inputs, estados, ícones e um card de programa para importação directa no Figma.
